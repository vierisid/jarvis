# What a sentence means today, pinned. Read by ./intents-corpus.test.ts.
#
# A section begins with "@ route" and the states it is under, or with "@ when" and the reader of a time.
# A row is:   sentence => what is done with it today   ## wrong: what is meant to happen
# The "## wrong:" part stands only on rows that are known to be wrong today (docs/notch/fixes/03-intent-routing.md).
# Such a row is pinned as it behaves now. The step that fixes it changes that row and takes the mark away.
#
# What is done with a sentence, as the test writes it:
#   <part>: <what the ledger says>     an intent of the one table took it (intents.ts). It is named by the part
#                                      that handed the intent over (pause, dayOne, mail, put, teach, people,
#                                      standing, agents, memory, calls, prefs, moves, canDo, said)
#   teach: ... (acts at once)          a shown job was done again: the hands were set to work with nothing asked
#   teach: ... (a line first)          a shown job was asked for, and "Do <the job> again?" came up for a yes
#   turn                               none took it: it goes to the assistant as an instruction
#   remember: <fact>                   none took it: it is written to memory
#   read+...                           it names somebody of the organisation, so the model was asked first what it
#                                      means (people.read). Here that model always answers "for nobody".
#   point(how|where; ...)+turn         it reads as a question about the window in front: the window was read and
#                                      what is named went to the model before the turn began
#
# The states (none named: nothing taught, nothing held, nothing up, Leo, Anna and Sam in the organisation, a
# spreadsheet in front, typed into Home):
#   job      a job was taught once, some time ago (nothing of it is fresh, and its window is not in front)
#   front    with job: the window the job was shown in is the one in front now
#   fresh    a job was shown a moment ago, the same thing done twice: where to go on from is fresh (3 minutes)
#   shown    a job was shown a moment ago, once (3 minutes). The only job there is.
#   choice   a line of choices is up: "Stopped at row 4. What now?" with Undo it, Watch me, Tell Anna, Continue,
#            Pause
#   held     a thing that was circled is held
#   draft    a draft of a mail reply is open on the notch
#   line     an offer is up on the notch: "Every day at 9:00, send me the news." with the key "make agent"
#   dayone   day one is on its talking step, waiting to hear the person
#   reply    the assistant has just asked "Shall I send it?" and the sentence is typed into that line as the reply
#            (with spoken: said with the talk keys while that question is up)
#   spoken   said with the talk keys held, not typed. The owner writes with nobody here, so no name that was
#            heard is ever read back ("Is that Anna Rossi?"): that step of the spoken path is not in this corpus.
#   browser  a browser is in front: a window that says too little about itself, so it can only be looked at
#   alone    no organisation: there is nobody whose Jarvis this one talks to
