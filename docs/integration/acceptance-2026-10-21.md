## Form submission processor and persistent duplicate prevention (2026-10-23)

- Added opt-in deterministic form handling to the built-in webhook. Set `settings.input.submission_id_field` and `submission_email_field` to the actual payload paths. Both are required together. Nested paths are supported; unknown mappings must be requested rather than invented. All string values are trimmed, the mapped email is lowercased and validated, and missing/invalid IDs or emails return HTTP 422 before any run is queued. Safe-integer IDs become strings; IDs remain case-sensitive. Email validation supports ordinary ASCII mailboxes, not quoted or internationalized addresses.
- The normalized ID is hashed and claimed in the existing SQLite delivery transaction together with the run and queue job. This prevents simultaneous or repeated webhook deliveries from creating another run, regardless of changing delivery headers. Manual runs use the same per-workflow identity. Identities survive restarts, republishing and run/history pruning; they become eligible for ordinary retention cleanup after the workflow itself is deleted. Isolated step previews cannot bypass the form guard.
- Inspected Google Sheets 0.18.2 `sheets_append_values`: real fields are `spreadsheet_id`, `worksheet_title`, `range`, `values` (2D array), and `value_input_option`. The builder now discovers the form contract and uses normalized trigger values directly with the inspected append action, preferably `RAW`. It does not need an AI transformation or a racy lookup-before-append.
- Added narrowly scoped authority and durable completion receipts for Sheets `insert_row`, `sheets_append_values`, and `sheets_add_row`. This does not promote the whole connector to VERIFIED. Completed effects return their stored result; a dispatch whose response/receipt is uncertain is not automatically resent. Accepted submissions that fail need inspection of the original run. This is at-most-once admission, not a guarantee that every accepted submission eventually reaches Sheets. No automatic provider readback or safe blind retry is claimed.
