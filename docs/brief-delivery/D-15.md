## Integrating the existing F-06 owner

The structural adapter consumes the existing `useBriefConversation()` result. It does not import the unmerged feature branch or create another store/socket. F-06 `23979f3bebab09a68c140aad3cb1843865fef150` is the inspected provider.

```tsx
const messages = bindConversationMessages(thread, "live");
<ConversationMessages mode="live" binding={messages}
  panelId="conversation" labelledBy={chatTabId("conversation", thread.state.activeId!)} />
```

Place it between the existing D-12 tabs and D-13 composer inside D-06's retained Pebble content. Use one authenticated F-04/F-06 provider above the shell. Supply the panel/tab ARIA relationship only for a selected conversation. The module compiles without those unmerged feature files; live mounting remains gated until the provider and combined release checks are available.

- Conversation, turn, request, activity and message identities are preserved. Foreign conversation/request events and tool/system messages are never rendered as response prose. Activities are ordered by their first observed sequence, not completion arrival.
- Public activity labels use F-06's fixed summaries. Unknown future summaries receive a generic label instead of exposing an arbitrary payload. Canonical goal/fact references select labeled colors, but record titles or reasoning are never guessed. The Figma sample's named goal/memory/notes copy is illustrative, not a runtime data source.
- `live` plus a running turn and connection selects the moving marker. Completed, failed and replayed rows stay still. Terminal failures/cancellation keep any partial answer; no raw error fields or tool arguments/results are displayed. Completed activities do not imply successful business effects.
- `client.store.setScroll` remains the durable reading-position owner. In-memory semantic block anchors refine that position during width/content changes and tab returns without creating another persistence mechanism. A workspace change retires those local view preferences.
- `client.loadOlder` owns pagination. Loading/error feedback stays local. The same selected conversation receives the scroll/history callbacks, even after another chat becomes selected.
- Auto-follow only applies while the reader is already near the bottom (24px). Activity toggles retain their local anchor; if a running row condenses, its own summary becomes the replacement anchor. A Latest messages control explicitly resumes following.
- Markdown uses the existing React Markdown/GFM dependencies. Raw HTML does not execute; unsafe/relative or credential-bearing links have no destination; external images render as text placeholders and cannot issue tracking requests. Code and wide tables keep their own horizontal overflow.

F-05 still owns attachment references and file handling. This step does not certify their final message rendering or file-only send integration. The preview's attachment fan is a cancellation-only fixture; it does not upload or capture.
