## Result

The official Pebble stays anchored to the workspace corner. Its surface unfolds upward and inward as the working column makes room. The existing room and one supplied conversation remain mounted, including during reversal, sidebar changes and navigation-readiness loss/recovery. The reading column is clipped rather than scaled. The close target stays at the panel's top-right; the composer can remain at the bottom while replies scroll independently.

On a narrow workspace, the same panel uses a single-pane layout. The working page becomes invisible and inert without losing its DOM, dimensions or scroll. Closing returns to the initiating control, with the opener as fallback. Escape is local to the conversation and respects a nested control that already handled it. Hidden conversation controls are inert. Reduced motion uses D-04, including live OS changes.

The root and onboarding/default-off behavior remain unchanged. No thread, socket, microphone, persistence, API request or domain writer was added.

## Integration contract for Lapo and other implementers

1. Continue in a separate worktree for the next task. Until this stack is merged, branch from the required D predecessor and target that predecessor in the PR. Do not merge this or another track's PR automatically.
2. `DashboardEntry` accepts an optional `conversation: { source, content }`. Supply the **one existing conversation** from the composition root. Do not mount a second live thread or transport in a room, this host, or the review fixture.
3. Live use requires the existing D-05/F-25 navigation gate and `source: "live"`. A fixture never supplies a live conversation. No binding means no opener or replacement chat. Temporary navigation-readiness loss hides the chrome while preserving a valid supplied conversation's component identity.
4. `NavigationShell` always renders `PebbleLayout`, even without a binding. Preserve that stable ancestor chain. Do not conditionally swap wrappers or key them by sidebar/chat/theme/selected object.
5. Room content keeps its `main` scroll container. `usePebbleWorkspace()` exposes `open`, `layout`, `workingWidth` and `conversationWidth`; the named CSS container is `brief-work`. Width includes the room's padding. Adapt the same room components through this contract, not duplicate mounted room variants. D-07 can extend the presentation contract for its approved goal-above-chat composition.
6. Supplied conversation content receives a flex column with `min-height: 0`. Its response body should scroll with `flex: 1; min-height: 0; overflow: auto`; bottom controls should be `flex: none`. The shell owns the panel close X. Reserve its upper-right 44px target rather than adding a second close control.
7. Mark the intended focus entry (normally the composer) with `data-pebble-focus`. Without it the panel itself is focused. Keep nested Escape handlers' `preventDefault()` behavior. Do not trap keyboard users in this nonmodal panel.
8. D-04 owns interruption and reduced motion. Resize measurements follow the containing workspace immediately so sidebar motion is not compounded by another delayed resize. Business state is never scheduled in animation-completion callbacks.
