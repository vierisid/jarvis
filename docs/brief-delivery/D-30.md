## Behavior and canonical boundaries

| Control                           | Behavior / owner                                                                                                                                                                                                                   |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Appearance                        | Light/Dark uses existing `jarvis-theme` storage and root `data-theme`. Every mounted selector subscribes; local changes, legacy root writes and cross-tab storage update together. Storage removal uses the bootstrap OS fallback. |
| Voice                             | Only F-23's listed standard spoken-response choices are selectable. Saves send `{revision, voice}` and require matching fresh readback. They never change provider, enabled state, credentials or other preferences.               |
| Natural realtime voice            | Opens existing voice settings through the host callback. The standard TTS preference is not treated as a realtime toggle or Pro entitlement.                                                                                       |
| Check-in frequency / active hours | Explicitly unavailable. Frequency choices are disabled with no selected value; there is no invented schedule.                                                                                                                      |
| Workspace controls                | Explicit Authority, Connected workspace and Advanced settings callbacks remain with F-25. Hosted provider setup stays managed.                                                                                                     |
| Tutorial replay                   | A native confirmation dialog delegates only `tutorial` to the existing reset owner. Profile/provider setup are preserved. Cancel/Escape return focus; an unknown outcome cannot be automatically repeated.                         |

Voice selection saves immediately. A failed/lost acknowledgment keeps the selected value and exposes **Retry save**. An explicit retry first reads the canonical value: an already-saved selection is confirmed without another write, while an external correction becomes a conflict. Conflicts require **Discard change and reload**. A failed reload retains the selection and blocks writes until a fresh read. Scope, capability or permission loss purges values and invalidates late results.

Persistence and application are separate: the UI distinguishes saved-and-applied, saved-but-restart-required, saved-but-application-failed, and unconfirmed live application after a lost reply. Application warnings survive normal polling. There is no automatic mutation retry.

The shared theme subscriber preserves the existing hook API and before-paint bootstrap. It reads the root through `useSyncExternalStore`; controls no longer maintain independent theme copies. Root, Brief panels, open menus and both mounted selectors change without replacing chat content or resetting sidebar state. No System choice or new storage key is introduced.

## Integration and activation

Merge prerequisite: **D-01**. Enable prerequisites: **F-23 and F-25**. Production registration and flags remain unchanged.

The host must create an authenticated, account-bound `createSettingsPort(scopeId, host)` and retain one `SettingsController` for that scope. Retire it on logout or account, transport or permission replacement. Provide all four destination callbacks (`authority`, `connections`, `voice-settings`, `advanced-settings`) through the navigation compatibility owner; local advanced/provider access must not be reused to expose provider setup on hosted installs. Supply an optional `replayTutorial: replayExistingTutorial` callback only where the existing tutorial owner is available.

Register with `settingsRegistration(binding)` using matching scope/source and current capabilities. Live rendering requires both enabled `profileSettings` and `navigationCompatibility`, plus all destination callbacks. Missing/mixed bindings fail closed; previews never substitute for a live provider. Verify the combined authenticated host, actual legacy destinations and hosted tutorial continuation before enabling. F-25 is not implemented by this card.

Shipped code imports no unmerged F-23 provider. The optional proof imports the exact clean provider checkout in a child process, uses a fresh temporary SQLite vault and secrets directory, and cleans them up. No network, audio or real account settings are used.
