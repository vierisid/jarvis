# D-32 — Runtime craft and accessibility verification

D32 adds a reusable browser/component verification harness and captures the current isolated Brief fixtures. **The harness is delivered; release verification is blocked.** The card explicitly permits the harness to land before enabled features. No D33 switch, capability registration, backend write or rollout is included.

The required manifest keeps all 19 room families, even unavailable destinations. It covers eight light/dark × expanded/rail × chat-open/closed endpoints with ready/long/empty/error data, six widths (1024/1280/1440/1920/800/390), 20 repeated interactions per room, keyboard probes and six explicit runtime review requirements per room. Missing fixtures, skipped capabilities and unexecuted requirements cannot produce a release pass.

## Remaining release gates

Workflow preview and draft registrations have no Body. Several existing specimens lack a meaningful long, empty or error state; those cases stay blocked, including completed-goal long content and empty memory detail. The report lists every missing case rather than substituting a nearby fixture.

No disposable enabled account or supported Jarvis sidecar was exercised. Real screen-reader output, actual OS/browser reduced motion, actual 200% zoom at the required widths, full visual reference comparison and live main journeys remain required. Native Ctrl+plus did not change CSS viewport/DPR in the available browser, so no zoom pass was recorded. A development-tool browser is not Jarvis WebView proof. The [runbook](../../scripts/brief-craft/README.md) defines the evidence needed to complete each requirement.

The verifier requires all 988 rows passed at the expected implementation revision, nonempty local artifacts, and one enabled-capability receipt per room. Fixture reports always block release. Human attestations must be truthful; the verifier checks completeness and artifact presence, not the truth of arbitrary supplied prose. D33 remains unstarted and gated on complete D32/F28/Q22 evidence.
