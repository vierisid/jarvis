## Handoff to Lapo and the F-04 integrator

The structural `ComposerOwner` port matches reviewed F-04 at `72f3078a4857e28ae6738c336f55f2988bf6f31b` ([PR #738](https://github.com/vierisid/jarvis/pull/738)). It avoids importing another unmerged feature branch. Consume the same existing owner as D-12:

```tsx
const conversation = useBriefConversation(); // F-04, after integration
const binding = bindConversationComposer(conversation, "live");
return <ConversationComposer mode="live" binding={binding}
  suggestions={suggestions} />;
```

- Mount the authenticated workspace's provider once above rooms. Do not key durable state to this field, a tab index, a title, appearance or the Pebble mount. The surrounding conversation content is a shrinking, scrollable flex child (`min-height: 0`); reserve the composer as a fixed flex child.
- Drafts are owner-controlled. The component invokes `client.store.setDraft(conversationId, text)`, `client.send(conversationId, text)` and `client.cancel({ conversationId, turnId, requestId })`. It never clears writing on dispatch or claims the response stopped before the owner changes its state.
- F-04 supplies pending acceptance and queued/running turn identity. The real owner's canonical acceptance clears only a matching unchanged draft. A newer draft survives. Stop captures the selected turn's exact IDs rather than consulting a later active tab.
- Cancellation intent belongs to that exact conversation/turn/request, not the dispatch promise. After dispatch returns, keep stopping feedback and permit an explicit Retry stop until the owner changes the turn, reports a new error or disconnects. A replacement turn retires the old local intent/lock; late callbacks cannot overwrite the new turn. Reconnection exposes Stop again without claiming the previous request completed. The adapter uses F-04's existing `store.setError(id, null)` before cancellation to clear only the request error, so an identical retry failure is observable. Do not use `dismissError` here: it would acknowledge the running turn and suppress a later terminal failure. No server state is changed by the local request-error reset.
- No active scoped conversation, missing workspace, wrong live/fixture source or unsupported mode yields a designed noninteractive fallback. Preserve the existing single-chat implementation in legacy mode at the integration boundary. Disconnection and metadata writes block send/stop but retain editable writing.
- The byte limit matches the inspected F-04 UTF-8 limit (65,536 bytes). Validate without truncating text. The owner remains authoritative. Pending calls are deduplicated locally; failed calls retain the draft and permit retry. An unmounted conversation ignores a late local error.
- Enter submits once, Shift+Enter inserts a newline. Composition state, native `isComposing`, keyCode 229 and the composition-end Enter guard protect IME input. Native textarea paste is plain text. No hidden model reasoning or unsupported rich-text processing is introduced.
- `attachmentControl` reserves D-14's 44px entry. F-05 owns selection/readiness/removal semantics; do not send attachments through this text-only port silently. The `label`, `placeholder`, suggestions and binding are reusable for workflow creation in D-16, but workflow creation is not wired here.
- The official SVG mark is cropped exactly as the existing opener, never redrawn. Shared interruptible motion controls 180ms intent/growth and 160ms exit; system/local reduced motion places the same result immediately. Keyboard focus supplies the same morph, and the tooltip uses 350ms pointer delay with immediate focus feedback.
