## For Lapo and parallel room authors

Own this change inside `ui/src/brief/styles/`. The two small entry/preview changes wire that isolated library into D-01; they do not register live rooms or providers. F owns domain behavior and Q owns reliability.

- Add `brief-root` around a Brief surface. It inherits the existing appearance choice. An explicit `data-brief-theme` may override that root for isolated references. Do not apply these aliases to the legacy root.
- Use semantic `brief-type-*` roles and `--brief-*` materials. The compatibility aliases for D-01 wrappers are deliberately inherited only within Brief.
- Use `brief-secondary` for important text on raised paper and menus. Dark tertiary text on that material measured 4.41:1 at 12px; the specimen uses the approved secondary role instead. No palette value was invented to hide the issue.
- A paper uses `brief-paper-object` outside `brief-surface brief-surface--paper`. The outer isolation keeps the backing behind the face; `brief-surface__clip` carries the same radius when clipping its contents. Do not put a rectangular shadow layer beneath it.
- Progress bands reproduce the approved rule: 0-19% near zero, 20-39% early, 40-74% middle, 75-100% near complete, gray remaining. These are visual classes, not new goal calculations. Always retain a readable value and unit.
- Status uses a labeled dot and surface; do not reuse a completion band to represent an error. Keep unknown data distinct from zero in future room adapters.
- D-03 owns control interaction states; D-04 owns motion. This specimen reuses the existing D-01 button and introduces no animation policy.
